# dataedittecnology

<!-- badges: start -->

<!-- badges: end -->

The goal of dataedittecnology is help the João Pinheiro Fundation to do
data analysis and quality.

## Installation

You can install the development version of **dataedittecnology** from
GitHub with:

``` r
# Install the 'remotes' package if you haven't already
install.packages("remotes")
remotes::install_github("FundacaoJoaoPinheiro/dataedittecnology")
```

## Example

This is a basic example which shows you how to execute the package:

``` r
## basic example code
library(dataedittecnology)
dataedittecnology::creating_report()
```
